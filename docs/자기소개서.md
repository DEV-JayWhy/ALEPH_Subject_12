# 자기소개서 | 박준영

**지원 분야:** 웹서비스 개발 / 프론트엔드·Java 웹서비스

## 실제 운영 중인 서비스를 개선하며 배운 개발
저는 금융기관 웹서비스와 실시간 관제 시스템에서 기능 개발부터 유지보수, 오류 개선까지 경험한 웹 개발자입니다. 새 기능을 구현하는 것만큼 이미 사용 중인 서비스의 불편을 찾고 개선하는 일을 중요하게 생각합니다.

## 금융 업무 흐름을 이해하고 다루는 책임감
2024년 6월부터 2025년 9월까지 휴노테크 플랫폼개발팀 협력 인력으로 기업 인터넷뱅킹과 기업 온뱅크 개발·유지보수에 참여했습니다. Vue·JavaScript 및 일부 Java 웹서비스를 활용하여 다단계 결재 과정, 이체·예적금·카드·대출 업무 처리 과정, 사업장 정보 등록 기능, FDS 고도화 업무에 참여했습니다. 기업 모바일뱅킹의 비대면 안면인식 관련 작업, 개인 인터넷뱅킹·라이프온·CUMall의 웹 접근성·취약점 조치도 수행했습니다. 금융서비스에서는 작은 수정도 여러 업무 흐름과 연결될 수 있기에 변경 영향 범위를 먼저 파악하는 태도를 익혔습니다.

## 관제 프로젝트에서 익힌 화면과 데이터의 연결
2021년 1월부터 2023년 8월까지 에쎄텔 소프트웨어팀에서 관제·관리자 웹페이지 개발과 유지보수를 담당했습니다. 대구시설공단 교통약자 배차 시스템의 이력 조회·운영 관리·스케줄 기능과 MariaDB 데이터 구조 개선에 참여했습니다. 실시간 드론 전파측정 및 WiFi 인지 스테이션 관제 과제에서는 측정·위치 데이터를 수신하고 관리 화면에 제공하는 일을 수행했습니다. 티머니 결제 시스템 관리자 화면은 Angular·TypeScript로 개발하고 Firebase Hosting과 Realtime Database 구조를 다뤘습니다. 화면, 서버, 데이터베이스를 함께 이해해야 문제를 끝까지 해결할 수 있다는 것을 배웠습니다.

## 계속 배우며 넓히는 역량
2026년에는 네트워크·보안·AI 교육에서 VLAN·OSPF·HSRP, DNS/DHCP, WEB-WAS-DB 구성과 웹앱 개발을 실습했습니다. 실습 중 모르는 부분은 질문하고 다시 테스트해 검증했으며 동료와 해결 방법도 공유했습니다. 교육 이력은 실무 경력을 대체하기보다 실무에서 부족했던 인프라·보안 관점을 보완하기 위한 과정입니다.

## 앞으로의 기여
기능을 구현하는 데서 끝내지 않고 사용자에게 필요한지, 운영 중인 환경에서 안전하게 동작하는지, 팀이 함께 유지할 수 있는지를 확인하는 개발자가 되겠습니다.

*기재된 프로젝트와 담당 범위는 본인이 제공한 실제 경력 정보를 기준으로 했습니다. 정량 성과는 제공되지 않아 임의로 작성하지 않았습니다.*
