# 경력기술서 | 박준영

**작성 원칙**  상황(S)–행동(A)–결과(R)별로 사실이 확인된 범위에서 기재. 수치·성과가 확인되지 않은 곳은 단정하지 않음.

## 1. 개발 직무 전환 · 2020년 대전 신성동

**능력**  자기조절력 / 자기동기력

- **상황** 지원했던 분야가 아닌 개발 업무를 담당했고 해당 분야의 선임 개발자 없이 혼자 담당.
- **행동** 자료 검색, 개념 학습, 오류 분석, 구현 결과의 반복 보완.
- **결과** 업무에 적응하고 뒤이은 웹 에이전트 개발 프로젝트를 담당할 기반을 쌓음.
- **근거** 과제 9 사용자 검토 1인칭 이야기. 회사명·정확한 재직기간은 미확인.

## 2. 대구 나드리콜 웹 에이전트 · 2021.08~2022.02

**능력**  자기동기력 / 자기조절력

- **상황** 사용자·운영자용 웹 에이전트 개발 및 이후 유지보수 필요.
- **행동** 전반적인 개발 작업, 이력 조회·운영 관리, 관리자 스케줄 유지보수, 기사 관련 테이블 및 스케줄 데이터 구조 개선. JSP, JavaScript, PHP, Java 웹 서비스, MariaDB 활용.
- **결과** 약 7개월의 개발 업무를 완수하고 퇴직 전까지 유지보수와 추가 개발 수행.
- **근거** 과제 9 포트폴리오 실무 항목. 성능 향상률·고객 수 같은 수치는 미제공.

## 3. 본사(HQ) 네트워크 프로젝트 · 2026.09

**능력**  자기조절력 / 대인관계력

- **상황** 팀 단위 단일 쇼핑몰 네트워크 구성 중 HQ 영역 설계와 동작 검증 필요.
- **행동** HQ VLAN 분리, 코어–분배–액세스 설계, OSPF/HSRP, 방화벽·라우팅 점검, WEB–WAS–DB 및 DNS/DHCP 구현과 연결 확인.
- **결과** HQ 내부 네트워크 및 로컬 3-Tier 서버 연결 검증. 단, 실제 ISP 인터넷 접근은 별도 사후 검증 필요.
- **근거** HQ 구축·검증 기록 및 2026.09.23 마무리 리추얼.

## 4. ALEPH 과제 6·8 · 2026.09~10

**능력**  자기동기력 / 자기조절력

- **상황** 데이터 기록 앱, 인증 기능의 구현·검증과 배포 재현이 필요.
- **행동** Supabase 테이블 및 정렬 조건 점검, 사용자 기능 실측, 인증 동작과 테스트 결과 검수.
- **결과** 계획 관리 앱 구성 및 실사용 검증 자료 확보; 인증 과제의 구현·검증 기록 정리.
- **근거** 과제 6~8 실습 기록. 팀/AI 기여는 역할에 따라 구분해 설명해야 함.

## 5. 학습 지원과 문제 해결 · 2026.08~10

**능력**  대인관계력 / 자기조절력 / 자기동기력

- **상황** 학습 진도가 다른 동료들의 반복 질문과 본인의 학습 공백 발생.
- **행동** 8/21 반복 질문 설명과 자력 검색, 9/03 진도 미달 팀원 지원, 10/13 진도 미달 사실 기록, 10/14 직접 입력하며 학습 복구.
- **결과** 동료 지원과 자기 점검 행동을 이어감. 정량적인 교육 성과는 아직 확인되지 않음.
- **근거** 2026-08-21·09-03·10-13·10-14 아침·마무리 리추얼.
