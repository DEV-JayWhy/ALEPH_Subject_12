# ALEPH Subject 12 — 개인 포트폴리오

웹사이트: https://aleph-subject-12.vercel.app

실제 금융·관제 웹개발 경력과 ALEPH 과정의 학습 기록, 보안 연구 대표작, 지원 문서를 정리한 개인 포트폴리오입니다.

## 구성

- `index.html`: 공개 포트폴리오(실무 경력, 이야기, 기록, 대표작, 지원 문서)
- `data/metrics.json`: 근거 자료의 집계 숫자. **2026-10-20 기준** 공식 훈련 46일·출석 45일·결석 0일·출석률 **97.8%**. 당일 출석 미확정 1일. 아침 리추얼 **45건**, 마무리 리추얼 **42건**
- `docs/`: 이력서·자기소개서·경력기술서 공개용 Markdown(휴대전화·생년월일·상세 주소 제외)
- `research/`: 과제 10 보안 논문 PDF에서 추출한 텍스트. 원본 PDF는 별도 자료

## 지표와 개인정보 주의

- 출석률은 공식 '내 출석 기록'의 제공 수치(2026-10-20)를 그대로 적용합니다. 오늘 1일은 아직 확정되지 않았으므로 추후 변경될 수 있습니다.
- 리추얼 건수는 `ritual-history-2026-10-20.json`의 날짜별 집계이며 **공식 출석률과는 다른 지표**입니다. 원본 리추얼 JSON·동료별 피드백은 공개 저장소에 업로드하지 않습니다.
- 전체 과제 제출률 자료는 아직 제공되지 않아 **공란**으로 표시합니다.
- 회사 경력 등은 본인이 제공한 실무 이력 기준이며, 수치로 확인되지 않은 성과는 추정하지 않습니다.
