# ALEPH Subject A — 개인 포트폴리오

박준영의 ALEPH 마지막 과제 A: 자기소개 사이트, 2026년 학습·리추얼 기록, 보안 연구 대표작, 지원 문서.

## 구성

- `index.html`: 공개 포트폴리오(로그인 없는 정적 사이트)
- `data/metrics.json`: 2026-10-15 기준 공개 가능한 수치. 출석 42/43, 97.7%, 당일 확정 전 1일, 아침 42건 / 마무리 39건, 과제 제출률 미입력
- `docs/`: 이력서·자기소개서·경력기술서 원문(Markdown)
- `research/`: 과제 10 보안 논문 PDF에서 추출한 전문 텍스트. 원본 PDF에 포함된 표·그림은 별도 원본 파일 참조

## 공개 전에 확인할 항목

재직 회사명·정확한 재직 기간·기술적 기여, 문서 표현을 본인이 검토합니다. 13주 최종 출석률과 과제 제출률은 자료가 생길 때 갱신합니다. 원본 리추얼 JSON 및 동료별 평가·연락처는 공개 저장소에 올리지 않습니다.

## Vercel 배포

정적 HTML 사이트입니다. Framework Preset은 **Other**, Root Directory는 **/**, Build Command는 공란으로 두고 GitHub `main`과 연결합니다. 현재 Vercel 계정 권한 연결 확인이 필요하며, 배포 완료 상태를 주장하지 않습니다.
